# lifesteal-queue — run with: /lifesteal-start (not /run-script lifesteal-queue)
# /lifesteal-start restarts Tor FIRST: scripts/restart-tor.sh --tor-only
# (the ONLY thing that brings up control ports 9051/9151/9251 this repo
# signals; `brew services restart tor` has no ControlPort 9051 -> NEWNYM
# gets ECONNREFUSED and no new circuit is requested). Then it sends NEWNYM
# on every local control port so reconnecting bots leave on fresh paths.
# This file documents the JS automation in lifesteal-queue.js. The .txt runner
# cannot do random picks / death replacement / collision / deathban loops, so
# the real automation is the /lifesteal-start command wired in bot.js.
#
# What /lifesteal-start does (role sizes are configurable — LIFESTEAL_DUELS_BOTS,
# LIFESTEAL_QUEUE_BOTS, LIFESTEAL_ARENA_BOTS, LIFESTEAL_TPA_BOTS, default 1
# each, 0 disables the role; live in the .ENV tab / /env set):
#   - LIFESTEAL_DUELS_BOTS random bots send /duelsroomqueue (on death a new
#     random bot is picked, same bot allowed again — no blacklist)
#   - LIFESTEAL_QUEUE_BOTS random bots send /queue (same replacement rule)
#   - LIFESTEAL_ARENA_BOTS random bots, never duels/queue/tpa holders, do
#     /warp arena, wait 5s, hold forward until they hit something (solid
#     block ahead or stuck), repeat
#   - LIFESTEAL_TPA_BOTS bots spam /tpa <player> round-robin over every
#     visible player until deathban (~24h: can still join server, just not
#     /server lifesteal), then a fresh random bot takes over and the banned
#     one is parked. LIFESTEAL_TPA_CMD switches the command to /tpahere so
#     each player gets pulled to the bot instead
#   - every other bot stays /warp afk (sent once)
#   - roster tops up to LIFESTEAL_TARGET_BOTS=20 via /new-gen, never removes
#   - banned bots count as missing: replaced with fresh /new-gen names so the
#     loop continues like nothing happened
#
# Commands:
#   /lifesteal-start | /lifesteal-stop | /lifesteal-status
#
# Standalone routines — each role on its own, no roster top-up, no /new-gen,
# no Tor restart (they just run on the bots that are already online):
#   /tpa-roundrobin [count|all] [stop]   the /tpa round-robin spam
#   /tpahere-roundrobin [count|all] [stop]  the same round-robin but always
#                                        /tpahere <player> (pulls players in)
#   /duelsroomspam [count|all] [stop]    the duels-room spam (re-sends every
#                                        LIFESTEAL_SOLO_REPEAT_MS, default 15s)
#   /queuespam [count|all] [stop]        the /queue spam (same cadence)
#   /warp-arena [count|all] [stop]       the warp → walk-until-hit loop
#   /afk-park [count|all] [stop]         park bots at the AFK warp (once)
# [count] limits the routine to that many bots (default: every online bot).
#
# Manual fallback (if you insist on plain scripts):
#   * /warp afk
